# 拍照换装

到景点拍张照，AI 把你身上的衣服换成衣橱数据库里的衣服 —— **只换衣服**，脸、姿势、景点背景不动。

> 参赛：支付宝智能体涌现奖 第一期（截止 2026-12-06 23:59:59）

## 核心链路

```
拍照（景点实拍）→ 上传 → 选衣服（手动 / 按天气风格自动）→ 换装引擎 → 出图 → 前后对比 → 保存 / 分享
```

## 模块划分

| 模块 | 说明 |
| --- | --- |
| 衣橱数据库 | 已有衣服 + 想试的衣服；每件 = 一张照片 + 类别（上衣 / 下装 / 连体）+ 来源标签；只试穿，不带购买 |
| 智能选衣 | 输入天气 + 风格偏好，输出排序后的候选；天气决定厚度 / 类别过滤，风格决定排序；用户始终可手动改 |
| 换装引擎 | 可插拔：输入 = 人像 + 一件衣服图，输出 = 换装图；引擎可替换（API / 本地 v1.5 / CatVTON），上层链路不动 |
| 成图与对比 | 原图 / 换装图并排对比；支持多次换装（先上衣后下装）；失败可重试（换种子 / 换衣服图） |
| 演示与投递 | 广州塔实拍 demo、60 秒视频、作品说明、封面、投递包 |

## 技术路线

- **第一步（验证，几天）**：FASHN API（v1.6，约 ¥0.5 / 张）跑一批广州塔实拍，验证「游客照换装」成不成。
- **第二步（产品化）**：本地部署 FASHN VTON v1.5（Apache-2.0 可商用，972M 参数，消费级显卡），API 作为备用引擎保留。
- **备选**：CatVTON（8GB 内可跑，非商用许可）。
- **不选**：IDM-VTON（14.6GB 显存超 8GB）、OOTDiffusion（老且不支持下装）、OmniTry（28GB+）、Qwen 20B（显存超）。

设计原则：成熟方案直接用，不自造轮子；自研只放在没有成熟产品的部分 —— 衣橱管理、自动选衣、景点场景闭环。换装引擎本身用现成模型 / API，不自训。

## MVP 范围

- **做**：上传游客照、衣橱上传与管理、手动选衣、按天气风格自动推荐、换装出图、前后对比、保存分享、广州塔 demo。
- **不做**：账号系统、视频换装、多人合影换装、购买链接、衣服抠图以外的编辑功能。
